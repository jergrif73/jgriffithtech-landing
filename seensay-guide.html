See 'n' Say: user guide

How to use all 15 tools on the See 'n' Say tab in Revit, step by step, and how to fix the problems people run into. Back to the product page.

Getting started

Install

  1. Close Revit.
  2. Run SeeNSay_Setup.exe from your purchase. No admin rights are needed.
  3. Choose your Revit version: Revit 2024, 2025, 2026, or all three.
  4. Start Revit. A short splash shows the version and counts the tools to 15/15, then the See 'n' Say tab is ready.

To update, run the newer installer over the old one; your settings are kept. To remove it, use Windows Settings › Apps and uninstall See 'n' Say. It asks Also remove saved settings?; answer Yes for a clean removal.

Sync Views

Inspection › Sync Views

Keeps open views lined up: pan and zoom across 2D views, and camera, visual style, detail level and section box across 3D views.

  1. Open the views you want to sync in Revit (tile them if you like).
  2. Run Sync Views. The window stays on top; it opens on Match 3D if the active view is 3D, otherwise on Sync 2D.
  3. Sync 2D: views are grouped by type and scale (only groups of 2 or more appear). Tick the views to include and pick the source with the round button.
  4. Match 3D: pick the owner (read from) with the round button and tick the views to write to. Under Match Options choose Visual Style, Detail Level (both on by default) and Section Box (off by default).
  5. Click Sync Now / Match Now for a one-time match, or Start Sync / Start Match to keep them matched. The window shrinks to a small floating panel with a red stop button; while it runs, whichever synced view you move drives the others.

All and Clear tick or untick every view. Element Visibility → (or EV on the floating panel) stops syncing and opens Element Visibility.

  • 2D syncing only changes zoom and pan, so it doesn't touch the model or Undo.
  • 3D matching changes the views' properties. Each one-time match is one Undo step; in continuous 3D mode every automatic update is its own Undo step.
  • 2D views must share the same view type and scale. Views opened after the window loads appear when you switch tabs or reopen the window.

Element Visibility

Inspection › Elem Visibility

Answers "why is this element showing in one view and missing in another?" by running about 25 checks on the view where it's missing and listing the likely cause.

  1. Run Elem Visibility. In Element Visibility - Setup, choose the element: Pick Element (click the instance in a view where it shows), Enter ID, Use Last, or the Recent list (your last 20).
  2. Pick the Source view (visible) and the Target view (missing). Type in either box to filter the list.
  3. Click Analyze. If you got the two views backwards, it offers to swap them.
  4. The results show the element, both views, the Target's view template (and whether it locks the category), the Likely cause, and a Visibility checks list (click to expand) with PASS, WARN and FAIL for each check.
  5. Copy Report puts a plain-text report on the clipboard for an email or RFI.

The checks include: worksets, category and subcategory V/G, view filters, Hide in View, graphic overrides (100% transparency), temporary hide/isolate, parts, detail level, discipline, phase and phase filter, design options, scope box, crop region, section box and annotation crop, level association, underlay, view range, plan regions, far clip, Revit links and imported categories.

It doesn't change your model. It reads the views, and for links it makes a temporary probe that is always undone. When nothing fails it lists other places to look (transparency, analytical model, view-specific elements, underlay, link overrides). Crop, section box and scope box tests use the element's bounding box.

Snoop Selection

Inspection › Look › Snoop Selection

A read-only inspector for any element: parameters, properties, bounding box and linked objects you can drill into, and a side-by-side compare when several elements are selected.

  1. Select one or more elements (or run it and pick when asked).
  2. The left panel lists your elements. The right panel shows Member, Value and Type, grouped into Object, Bounding Box, Fields, Properties, Indexers, Methods and Parameters.
  3. Double-click a linked row to drill into it; Back and Home step out. Double-clicking an element or ElementId row selects that element in Revit and zooms to it.
  4. Search filters rows as you type. With 2 or more elements, Similarities shows values they share and Differences shows values that vary.
  5. Copy puts the selected rows (or all rows) on the clipboard, tab-separated for Excel. Export CSV writes %TEMP%\snoop_selection_export.csv.

It never changes the model. The window keeps Revit busy until you close it. Geometry members are left out.

Super Filter

Inspection › Look › Super Filter

Narrows a set of elements by unchecking what you don't want, by category, family and type or by any parameter value, then selects the rest in Revit.

  1. Pick a scope on the right: Current Selection (loads automatically if something was selected), Elements Visible in View, Elements Belonging to View (annotation and detail items) or All Model Elements.
  2. On the Categories tab, uncheck what you don't want in the All › Category › Family › Type tree. Or use the Parameters tab: All › parameter › value (blank values show as "(empty)").
  3. The footer counts what's left. Select puts it into the Revit selection and closes.
  • Update Selection narrows the working set to what's checked and rebuilds both tabs, so you can filter by category and then by parameter.
  • Box-Select to Add lets you drag a box in the view to add more elements, then returns.
  • Expand All, Collapse All, Check All and Uncheck All act on the open tab.

The result comes from the tab that's open when you click Select. It only changes the selection, never the model. Very large "All Model Elements" scopes can take a moment to load.

Compare

Inspection › Look › Compare

A side-by-side table of properties for fabrication parts, families, schedules or views, with differences highlighted.

  1. Choose a Mode: Elements, Families, Schedules or Views (the last mode is remembered).
  2. Click Select Items:
    • Elements: pick 2 or more fabrication parts (or have them selected first).
    • Families: choose categories, then exactly two families, then what to compare: Family Properties, Family Parameters, Family Types.
    • Schedules: choose 2 or more schedules, then Fields, Filters, Sorting/Grouping, Field Formatting.
    • Views: choose Project Views or View Templates, exactly two, then Model, Annotation, Analytical and Imported Categories, Filters, Worksets, Revit Links.
  3. Use Everything, Differences or Same to filter the table. Export CSV and Export XLS save all rows.

Compare only reads; nothing in the model changes. Elements mode works with fabrication parts only. The table shows up to 10 items side by side; exports include every item.

Find Sheet

Inspection › Look › Find Sheet

  1. Select a view in the Project Browser.
  2. Run Find Sheet. If the view is on one sheet, it asks to open it. If it's on several, pick one from the list (up to 4 are offered). If it isn't on a sheet, a notice says so.

Schedules and view templates aren't supported. Nothing in the model changes.

Duct Orient

Inspection › Duck › Duct Orient

Checks that each rectangular fabrication duct's labeled Width really is the horizontal side (and Depth the vertical), by reading the connector geometry, and fixes the ones that are turned 90°. Works on horizontal, sloped and vertical runs.

  1. Load parts: select fabrication duct first, or use Pick Elements, All in View or Visible.
  2. Click Analyze. The table lists each part's Id, Service, Labeled size, Actual orientation (H x V) and Status: Correct, MISMATCHED, OK (Square) or Skipped. Mismatched parts are listed first and selected in Revit.
  3. Fix Mismatched rotates each mismatched part 90° about its own axis (one Undo step) and re-checks.
  4. Select in Revit selects and zooms to the mismatched parts; Export CSV saves the table.

Parts need Main Primary Width and Depth and a rectangular connector; others are skipped. Analyze doesn't change the model.

Coil Duct

Inspection › Duck › Coil Duct

Works out each rectangular fabrication straight's overall cut length (body length plus the two connector allowances), checks it against your coil width, tags the result and colors the parts in the active view.

  1. Set Coil Width (default 60 in) and Write tags to (Comments or another text parameter).
  2. In Valid Coil Connectors, tick the connectors that can go on the coil line and set each one's Allowance (in). The defaults are None, RAW, RAW 1 NOTCH and DM 35 at 0", S&D and S&S at 0.5", and TDC at 1.875". Scan Model or Scan Database adds connectors you use (unticked, at 0").
  3. Select parts, or use Pick Elements. Click Run Analysis. With nothing selected it offers to check all fabrication duct in the model.

Colors go on the active view only, and old tags and colors aren't cleared before a new run.

Renumber

Designation › Renumber

Writes sequential numbers (with prefix, suffix and zero padding) into one to three parameters, in an order you control, with an option to give identical parts the same number.

  1. Select elements (or use Pick Elements). Trim the set with Deselect Elements (by individual, category, family, type or parameter value) or Filter Selection (keep one parameter value).
  2. Set Target A (required), and optionally Target B and C. Assembly Mark and fabrication Item Number are available.
  3. Set Prefix, Start (default 1), Suffix and Pad (digits, for 001-style numbers).
  4. Choose Ordering:
    • Group: All at Once, By Category, By Family, By Type, or Order by Parameter. Group Order sets which group comes first. Numbering continues from one group to the next.
    • Order: Largest → Smallest, Smallest → Largest, Clockwise, Counterclockwise, or Follow spline (click Pick Curve).
    • Or tick Manual pick order and click Pick Order, then click elements in the order you want; Esc when done.
  5. Optional: Same number for identical parts, with the fields to compare (fabrication fields like Alias, CutType, Gauge, Service; common fields like Size, Length, Material) and a Length tolerance from Exact to 1". Include nested families. Place TextNote tags after renumbering (uses a text type named "Renumber Tag" if you have one).
  6. Click OK, or Run & Place Tags to number and then open Place Tags for the same elements.

Renumbering is one Undo step (TextNotes are a second). Writing to Item Number also fills CP_Item Number if you have it. Save and Load keep setups as .xml profiles; otherwise your last settings are remembered until Revit closes.

Place Tags

Designation › Place Tags

Tags many elements across categories in one go, with offset, rotation and leader control.

  1. Select the elements to tag, or click Select Elements in Revit. Include Nested Families adds nested instances when you pick.
  2. The Tag Configuration list shows each category, its count and the tag it will use (picked automatically from loaded tags). Double-click a row to choose a different tag, or to load a tag family (.rfa) if none is loaded.
  3. Set Offsets in inches: Up/Down (default 12") and Along (default 0").
  4. Set Orientation: In-Line, Horizontal, Vertical or Perpendicular, plus an Extra Angle. Choose a Leader: None, Attached End or Free End (with a Shoulder length).
  5. Leave Skip Already Tagged on to avoid duplicates on reruns. Click Place Tags.

Tags go in the active view, one Undo step. Save the setup as a profile (name it and click Save As) and pick it from the list next time. The notice reports how many were placed, skipped and failed; an element fails when its category has no tag assigned or no placement point.

View Converter

Designation › Spin › View Converter

Turns a Legend into a Drafting view, or a Drafting view into a Legend, by rebuilding its contents.

  1. Choose Legend → Detail or Detail → Legend, then the source view. The Summary shows what was found and what will be rebuilt.
  2. Options: Delete source view after conversion (off), Open result view (on), Zoom to fit (on).
  3. Click Convert. The new view gets the source's name and scale.

Rebuilt: detail lines and curves, text notes, filled regions, generic annotations and dimensions (a dimension comes back when at least two of the things it measures were rebuilt). Legend Components can't be carried over to a drafting view. Detail → Legend needs at least one existing Legend in the project. It's one Undo step, including deleting the source.

Toggle Case

Designation › Spin › Toggle Case

  1. Select text notes, or click Select Elements in Revit (only text notes can be picked).
  2. Choose Auto-Cycle (like Shift+F3 in Word: UPPERCASE → Title Case → lowercase, based on the most common case in your selection), UPPERCASE, Title Case or lowercase. The Preview shows the result.
  3. Click Apply. The window stays open so you can apply again; each Apply is one Undo step.

Save a favorite mode as a profile. Title Case capitalizes every word, so acronyms like HVAC become Hvac. Tags and dimension text aren't changed.

Rotate Multiple

Designation › Spin › Rotate Multiple

Rotates many elements, each about its own center, which Revit's Rotate can't do.

  1. Select elements or click Pick Elements. Trim with Deselect by individual, category, family or type.
  2. Choose Manual (every element turns by the angle you type, default 90°) or Align to Reference (each element turns to match a direction: Pick Reference on a duct, pipe, line, grid, scope box or family, or Two Points; then Parallel or Perpendicular).
  3. Axis: World Z (Up) or View Normal. Center: Auto or Force BBox (more reliable for odd shapes).
  4. Click Rotate. Pinned elements are skipped unless you allow unpinning (the checkbox, or Yes when asked); they're re-pinned afterwards.

The whole run is one Undo step. The notice reports how many rotated and how many were skipped.

Convert

Designation › Spin › Convert

Replaces fabrication ductwork with native Revit ducts and fittings.

  1. Load parts: select fabrication duct, or use Pick Elements, All in View or Visible.
  2. Choose the engine. Work in this order: Straights, then Elbows, then Transitions, then Taps. Elbows and taps connect to native duct that already exists in the active view, so straights must come first.
  3. Leave Delete originals after conversion on (default) to replace the fabrication parts, or turn it off to keep them.
  4. Click Convert. The results list says what was created, skipped and why.

The run is one Undo step. Native ducts copy workset, phases, Comments, Mark and System Name. The model needs a native Duct Type for each shape and at least one Mechanical System Type. Taps work on round and rectangular duct.

Set Hangers

Designation › Spin › Set Hangers

Sets Generic Model hanger families to the duct or pipe they hold: bottom-of-hanger elevation following the slope, clamp size, trapeze width and insulation (Lower Attachment), and top depths or offsets following a sloped line (Upper Attachment).

Lower Attachment (BOH from duct or pipe)

  1. Choose the content: Current Selection, Active View or Entire Model, or Pick Content. Duct, pipe and fabrication duct and pipe all work.
  2. Click Scan for Hangers. Hangers within the Max hanger distance (default 1 ft) of each run are listed; distances over 0.5 ft show in orange so you can double-check them.
  3. Insulation is read automatically, or choose the parameter that holds it. Elevation offset stores a per-family adjustment in inches (select a row, type, click Set).
  4. Click Sync Lower. Each hanger gets its bottom elevation (CP_Hung Object Bottom Elev, BOHElevation or CP_Bottom Elevation), diameter, trapeze width and insulation, and is centered on the run.

Upper Attachment (follow a slope line)

  1. From the start window click Pick Hangers, or use the hangers from a scan.
  2. Click Pick Line and click the model line that sets the slope.
  3. Click Sync Upper (or Sync Both). Hangers with structural-depth parameters get those set; others get Top Offset, or move in height.

Quick Sync

Quick Sync: Pick Part + Hanger on the start window syncs one hanger to one duct or pipe without the list, after asking whether to hang outside the insulation or on the bare surface.

Each Lower hanger is its own Undo step; Upper is one step. Status shows per row (Ready, Synced, Outside Range, No writable elevation param and so on). Settings, including per-family offsets, are remembered.

Troubleshooting

There's no See 'n' Say tab
Check that your Revit year was ticked in the installer: there should be a JGriffithTech.SeeNSay.addin in %AppData%\Autodesk\Revit\Addins\<year>. Revit 2024, 2025 and 2026 are supported. Run the installer again with Revit closed.
"The See 'n' Say add-in failed to load"
Close Revit, run the installer again, and restart. If it keeps happening, email the error text it shows.
A tool says "Open a project first"
Open a project (not a family) and run it again.
Element Visibility: "You picked a Type" or "That Id refers to a Type"
Pick the element itself in a view, or enter an instance's Element ID, not its type.
Element Visibility finds nothing
Check the suggestions it lists (transparency, analytical model, view-specific items, underlay, link overrides). Some Revit visibility rules can't be read through the API.
Compare: "Need at least 2 fabrication parts"
Elements mode compares fabrication parts only. Pick two or more; other elements are ignored.
Find Sheet: "Select a view in the Project Browser first"
Click a view (not a schedule or template) in the Project Browser, then run it.
Convert: "No native Duct Type found for shape"
Draw a short native duct of that shape, or use Manage › Transfer Project Standards › Duct Types, then run Convert again.
Convert: "no native endpoint near… (convert straights first)"
Run the Straights engine first; elbows and taps attach to native duct in the active view.
Coil Duct: "Enter a valid coil width in inches"
Type a number greater than 0 in Coil Width.
Coil Duct: a part has no tag or color
Parts that are already coil and correct, round or oval parts, and non-coil parts with unticked connectors are left alone. Colors go on the active view only.
Duct Orient: everything is "Skipped"
Parts need Main Primary Width and Depth and a rectangular connector. Round and oval duct is skipped.
Place Tags: elements counted as "Failed"
Assign a tag to each category (double-click its row) or load the tag family. Elements with no placement point can't be tagged.
Renumber: "No elements were updated" or "target skipped"
Check Target A is a parameter the elements have and that it isn't read-only (for example a type parameter or one driven by a formula).
Rotate Multiple: "Skipped" elements
Pinned elements are skipped unless you allow unpinning. In Align mode, elements without a readable direction are skipped.
Set Hangers: "No hangers found"
Hangers must be Generic Model families placed at a point. Raise Max hanger distance and click Re-Scan.
Set Hangers: "No writable elevation param"
The hanger family needs one of CP_Hung Object Bottom Elev, BOHElevation or CP_Bottom Elevation as a writable instance parameter.
Set Hangers Upper: "Outside Range" or "No slope line"
Click Pick Line and pick a model line that runs past every hanger you want to set.
View Converter: "No existing Legend views found to use as template"
Create one Legend view in the project (View › Legends), then convert Detail → Legend again.
