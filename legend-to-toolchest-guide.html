1What it does

Legend to Tool Chest takes the symbols you want from a drawing legend and turns them into a Bluebeam Revu tool set. Every symbol becomes a sharp vector stamp in your Tool Chest, already named from the legend. No redrawing valves, instruments or fittings by hand, and no need to set up a whole drawing set when you only need a handful of symbols.

You snip the legend rows you want, paste them in, answer a few questions, check the results, and press Add to Revu.

2Quick start

  1. Open Legend to Tool Chest from the Start menu or your Desktop. It opens in its own window.
  2. In your PDF, zoom in on the legend, then press Windows + Shift + S and drag around the rows you want. Include the names beside or under the symbols.
  3. Click the paste area in the Legend to Tool Chest window and press Ctrl + V. Paste as many snips as you like. (To pick a saved image instead, press Browse for an image.)
  4. Answer the questions: a name for the tool set, how tall a typical symbol should be, how names and colors should look, and the line weight.
  5. Check each card. Fix any name by typing over it, untick anything you don't want, and click a picture to change that symbol's color.
  6. Press Add to Revu. The new tool set appears at the bottom of Revu's Tool Chest.

3Taking good snips

The snip is everything the tool has to work with, so a good snip gives clean tools.

  • Zoom in first. Zoom the PDF 2 to 3 times before you snip. Aim for legend text at least about 30 pixels tall on screen. If a snip is small, the app tells you so.
  • Include the names. Names can sit to the right of the symbols (most P&ID and plumbing legends) or under them (duct fittings and equipment legends laid out in a grid). The app works out which; if it guesses wrong, change the Names choice under that snip to beside or below and it reads the snip again.
  • Dimension notes stay with the drawing. Notes like R=1-1/2D, D1 or L drawn around a fitting become part of its stamp. Don't want them? Use Fix boxes and box just the fitting.
  • One legend column at a time for names-beside legends. If it has two or three columns side by side, snip each one separately. A names-below grid can be snipped whole.
  • Leave out borders and titles you don't need. Long table lines and frames are ignored, but a tight snip is cleaner.
  • Any snipping tool works. Windows Snipping Tool, Snagit, or Revu's own Snapshot. You can also drop image files (PNG, JPG, BMP) onto the window or click it to browse.
Tip: solid black line work traces as exact outlines, so arrowheads stay pointed and junctions stay crisp. Very faint gray hairlines are traced along their centers instead and drawn with an even pen.

5Fixing a tool (Fix boxes)

Sometimes two symbols touch and come out as one tool, or a tool picks up the wrong line work. Fix boxes lets you say exactly where each symbol and its name are.

  1. Press Fix boxes under the snip at the top, or click the Snip link on any card.
  2. The snip opens large. Each tool shows a gold box around its symbol and a dashed box around its name, with its number and name on a label.
  3. To remove a wrong tool, click its box and press Delete (or Remove selected).
  4. To add a tool, drag a box around one symbol (just its line work), then drag a box around its name. If there's no name to box, press No name box, I'll type it and type the name on its card afterwards.
  5. Press Done. Your new tools slot into the list where they sit on the snip.

Clear all on this snip removes every tool found on that snip so you can box each one yourself. Esc cancels a box you've started.

Tip: a box only takes the ink inside it. Draw it snugly around the symbol so it doesn't catch the end of a neighboring symbol.

6Line weight

Screenshots often make line work look heavier than the CAD pen it was drawn with. Drag the Line weight slider between Thinner (30%) and Thicker (200%). The pictures update as you drag, and the tool set is built at the weight you see. Reset puts it back to 100% (as snipped).

Tip: at the thinnest settings very fine details can start to break up. Ease back up a little if a symbol loses pieces.

7Colors

Every symbol can have its own color. Click a symbol's picture (or tab to it and press Enter) to open the Symbol color panel.

  • Labeled swatches: As snipped BlackGrayRed OrangeGoldBrown GreenTealCyan BlueNavyPurple MagentaWhite
  • Custom color: open the color box for any shade, or type a hex code such as #3366CC.
  • Use for all tools: gives every included tool the color you have selected.
  • As snipped returns the symbol to the colors from the drawing.

Each card shows its color under the name, for example Color: Red. A color picked on a card always wins over the Keep colors / All black choice.

8Getting it into Revu

  • Add to Revu saves the tool set and hands it to Bluebeam Revu, which imports it and shows "Successfully Imported Tool Set". Look for it at the bottom of the Tool Chest panel.
  • Save file only saves the tool set (a .btx file) without opening Revu. Use this to share a set with a coworker.
  • To place a symbol, click it in the Tool Chest and click on your drawing. It goes down at the size you chose. Like any stamp, you can resize, rotate and recolor it in Revu afterwards.
  • Each stamp's Subject is the tool's name, so it shows up properly in the Markups List and in quantity reports.
Works with: Bluebeam Revu 21 (tested). Other recent Revu versions read the same tool set format.

9Managing tool sets in Revu

Add a saved tool set by hand

In Revu: Tool Chest panel, then Manage Tool Sets, then Add, and pick the .btx file.

Delete (remove) a tool set

  1. Open the Tool Chest panel and click Manage Tool Sets.
  2. Select the set and click Remove, then OK.

This takes it out of Revu. The .btx file stays in your Documents folder, so you can add it back later or delete the file too.

Make a better version

Build the set again. If Revu now shows the old and the new set, remove the old one with the steps above.

10Where files go

Every tool set is saved to Documents\JGT Legend Tool Sets, named after the tool set. After a build, click Open folder to go straight there.

12Troubleshooting

What you seeWhat to do
"Windows protected your PC" when installingThe installer is new to Windows' reputation list. Click More info, then Run anyway.
Nothing seems to openLook for a window called Legend to Tool Chest on the taskbar. If you just closed it, wait a few seconds and open it again.
"The clipboard has no picture"Snip first with Windows + Shift + S, then paste.
No symbols found, or names on the wrong symbolsMake sure the names are in the snip, then try the Names choice under the snip (beside or below). Still off? Use Fix boxes.
Clicking the paste area doesn't open anythingThat's on purpose: click it, then press Ctrl + V. To pick a file, press Browse for an image.
Two symbols became one toolThey touch on the drawing. Use Fix boxes to box each one.
A name is misreadType over it on the card. Names are read by the text reader built into Windows, which sometimes swaps similar letters.
Symbols look rough or blobbyZoom in further before you snip, then try the Line weight slider.
"Revu wasn't found"The tool set is still saved. Add it by hand: Tool Chest, Manage Tool Sets, Add.
The tool set isn't in the Tool ChestScroll to the bottom of the Tool Chest panel. New sets are added last.
Installing an updateJust run the new installer. It closes a running copy for you.

13Privacy and offline use

Everything happens on your PC. Snips are read by the text reader built into Windows, the window talks only to the program on your own computer, and nothing is uploaded anywhere. It works with no internet connection.

14Install, update, uninstall

  • Needs: Windows 10 or 11 (64-bit) and Bluebeam Revu. Chrome or Edge for the window (one of them is on every Windows PC).
  • Install: run JGT-Legend-to-Tool-Chest-Setup.exe. No admin rights needed; it installs for your user account and adds a Start menu entry, an optional Desktop shortcut, and this guide.
  • Update: run the newer installer. Your saved tool sets are not touched.
  • Uninstall: Windows Settings, Apps, find JGT Legend to Tool Chest, Uninstall. Your saved tool sets in Documents stay.
