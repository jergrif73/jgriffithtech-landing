How to use it

  1. In Forma Model Coordination, open a clash check and set Group clashes by to Object Name.
  2. Click the gold JGT Clash Export button at the right end of the viewer toolbar.
  3. Check the counts, pick the report name and coordinates, then click Export and choose a folder.
  4. In Navisworks: Saved Viewpoints, right-click, Import Viewpoints. Sets, right-click, Import Search Sets.

Activate Pro

  1. Buy Pro on Gumroad. Got a team code? Enter it at checkout.
  2. Copy the license key from your receipt.
  3. Right-click the extension's icon in the Chrome toolbar, choose Options (or click License at the bottom of the export panel), paste the key and choose Activate.
  4. Close and reopen the export panel.

Help

  • No gold button on the toolbar: reload the Forma tab after installing or updating.
  • "Set Group clashes by to Object Name": that's the grouping the export reads. Change it in the clash panel and open the export again.
  • A viewpoint lands in the wrong place: export again with the other coordinate option (Shared or Internal), to match how the models were exported from Revit.
  • Chrome asks to let acc.autodesk.com edit files: that's Chrome's rule for any site writing into a folder you picked. Allow it once.
  • Moving to a new computer: remove the key on the old browser's options page, then activate it on the new one. Each key covers up to 5 browsers.
