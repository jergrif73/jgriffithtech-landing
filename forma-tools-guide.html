Getting started

  1. Install the extension from the Chrome Web Store.
  2. Open or reload (F5) a project in Forma Model Coordination and open a model in the viewer.
  3. Wait for the model to finish loading. Tools that run too early say "The model is still loading".

There are three ways to reach the tools:

  • The JGT button on the viewer toolbar at the bottom of the 3D view (a navy square with a gold "ID") opens the full menu.
  • Right-click a part for Copy Element ID, Copy ID + Details and Select Same.
  • Keyboard shortcuts, which work even while Forma's search box has focus:

Everything only reads. Nothing in Forma or your models is changed, and your model data never leaves your computer.

Copy Element ID Free

  1. Select one or more parts in the 3D view or the model browser.
  2. Press Ctrl+Shift+E (or right-click › Copy Element ID).
  3. A toast confirms what was copied, for example "Copied 3 IDs".
  4. In Revit: Manage › Select by ID, paste with Ctrl+V, and click Show or OK.

IDs are separated by ;, the format Revit's Select by ID expects. Duplicates are removed. Up to 5,000 parts per copy.

Copy ID + Details Free

Ctrl+Shift+Alt+E copies one line per part: Element ID, name and the file it came from. Paste it into Excel and it lands in three columns. Use it when parts come from several models, because Revit IDs are only unique within one file.

Find by Element ID Pro

  1. Press Ctrl+Shift+F (or JGT › Find by Element ID).
  2. Paste IDs: one per line, or separated by ;, commas or spaces. A Copy ID + Details paste works too (the first column is used).
  3. Pick All loaded models or one file.
  4. Click Select and zoom, or Isolate to hide everything else. Show all brings the rest back.

The results list how many were found in each file, which IDs weren't found, and any ID that exists in more than one file.

Quick Properties Pro

Press Ctrl+Shift+H to turn on a hover tooltip, like Navisworks' Quick Properties. Hover any part to see its Element ID, name and file, plus Category, Level, System Abbreviation, Size and Length. Press the shortcut again to turn it off.

To change the fields: JGT › Quick Properties fields…. Type property names exactly as Forma's Properties panel shows them (Family and Type work too). The choice is saved in your browser.

Select Same Pro

Select a part, right-click it, and choose Select Same › Type, Family, Category, Level, System Abbreviation or Size. Everything matching is selected across all loaded models. Combine it with Copy Element ID to send a whole system to Revit.

Appearance Profiler Pro

  1. JGT › Appearance Profiler.
  2. Pick a property: System Abbreviation, Level, Size, Category, Family, Type, File, Material and so on.
  3. Parts are colored by value. The first 12 values get their own colors, any further values share gray, and blank values stay uncolored.
  4. Click a row in the legend to select those parts.
  5. Clear colors puts the model back.

It's off in the Clashes view, because coloring there would hide Forma's red and green clash colors. Clear colors resets every custom color in the viewer, including colors from other tools.

Export and takeoff Pro

  1. JGT › Export properties.
  2. Choose which parts: the selection, the visible parts, or all loaded models.
  3. Choose columns. The defaults are Element ID, Name, File, Category, Family, Type, Level, System Abbreviation, Size and Length.
  4. Download CSV, or Copy table for Excel and paste.

Takeoff: group by one property and total another, for example count and total Length by Size. Lengths show in feet and inches to 1/16" plus a decimal column.

In the Clashes view

Forma's Clashes view doesn't keep a normal selection. To copy one part's ID there, click the part itself in the 3D view, then press Ctrl+Shift+E. The extension remembers the last part you clicked.

  • Pro Copy clash objects (A and B): copies every highlighted clash object as Side, Element ID, Name, File. Side A is Forma's red, side B is green.
  • Pro Clash objects by level: counts the highlighted clash objects on each level, split by side, ready to copy or save as CSV. It counts objects, not clash pairs, because Forma doesn't say which objects pair up.

Activate Pro

  1. Buy Pro on Gumroad ($9.99 one-time). Got a team code? Enter it at checkout.
  2. Copy the license key: it's on the purchase page Gumroad opens after checkout, and in your receipt email (four blocks of eight letters and numbers).
  3. Click the extension's icon in Chrome's toolbar. Its options page opens.
  4. Paste the key into License key and click Activate. It says "Pro is active".
  5. Reload your Forma tab (F5).

A key works in up to 5 browsers. The extension re-checks it with Gumroad about once a week, and stays Pro for 30 days if Gumroad can't be reached.

Moving to a new computer

On the old browser, open the options page and click Remove key from this browser. Then activate the same key on the new one.

Troubleshooting

The shortcut does nothing, or there's no JGT button on the toolbar.
Reload the Forma tab (F5). Chrome only adds the extension to pages opened after it was installed or updated. Check that the extension is switched on in chrome://extensions.
"Select a part first" in the Clashes view.
Click the part itself in the 3D view, then press the shortcut. A click in the clash list doesn't count as selecting the part.
"The model is still loading".
Wait for the progress bar at the top of the viewer to finish, then try again.
"Open a model in the viewer" while a model is open.
Reload the tab. If it keeps happening, a Forma update may have changed something the extension reads. Please let me know (contact below).
Revit's Select by ID can't find an ID, or finds the wrong part.
Make sure the Revit model you have open is the same file the part came from: IDs repeat across files. Copy ID + Details shows the file for each ID. A picked type row in the model browser gives the type's ID, not an element's.
"That license does not exist for the provided product".
Check the key is for JGT Forma Model Coordination Tools Pro (not another JGT product) and was pasted whole, with no extra spaces.
"This key is already active on 5 browsers".
Remove it from a browser you no longer use (options page › Remove key), or contact me to reset it.
Pro turned off by itself.
Gumroad reported the purchase as refunded or disputed, or the key couldn't be checked for over 30 days. Open the options page and click Check license now.
