Install

  1. Download the zip (also on your Gumroad receipt) and unzip it. Right-click, Extract All. Don't run the files from inside the zip.
  2. Close Navisworks, then double-click Install.cmd. No admin rights needed. If Windows SmartScreen appears, choose More info, then Run anyway.
  3. Start Navisworks Manage 2026 and open the JGT ribbon tab.

To install for every user on a machine, run powershell -ExecutionPolicy Bypass -File .\Install.ps1 -AllUsers as administrator in the unzipped folder. To remove it, double-click Uninstall.cmd.

Free trial and license

  1. Open any of the tools. Until it's licensed, it shows a card with Start free 30-day trial. No signup or key.
  2. Bought one? On the JGT tab click Settings › License, paste the key from your Gumroad receipt, and click Activate. The bundle key unlocks all three.
  3. A key works on up to 5 computers. Moving to a new one? Click Remove next to the key on the old computer first.

Help

  • No JGT tab: check that you started Navisworks Manage 2026, then run Install.cmd again.
  • "File in use" during install: Navisworks is still open. Look for Roamer.exe in Task Manager.
  • A tool still shows the locked card after activating: open Settings › License and click Check keys now. The key has to be for that tool or the bundle.
  • No internet: a key checked once keeps working offline for 30 days.
  • The Section pane won't stay docked: drop it with the pointer on a docking guide icon, while the blue shadow shows.
