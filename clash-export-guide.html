Getting started

  1. Install the extension from the Chrome Web Store.
  2. Reload (F5) any open Forma tab so the extension can add its button.
  3. In Model Coordination, open a clash check (Selection A against Selection B).
  4. Set Group clashes by to Object Name, and let the "N clash groups" list finish loading. Keep both models loaded in the viewer: that's how each clash is located for its viewpoint.

Export

  1. Click the gold JGT Clash Export button at the right end of the viewer toolbar (or the extension's icon in Chrome's toolbar). The panel opens over the viewer.
  2. Check the counts: groups and clashes read, and how many groups were located in the viewer. They should match the Forma panel header.
  3. Set the project and report name (used in the file names), and the Navisworks coordinates: Shared (the usual Revit export) or Internal. Pick Both if you're not sure.
  4. Tick the files you want. Skip inconsequential viewpoints leaves the touches and minor hardware out of Navisworks.
  5. Click Export and pick a folder. Every file is saved there. Cancel the folder window and nothing is saved.

The first time, Chrome may ask to let acc.autodesk.com edit files in that folder. That's Chrome's rule for any site saving into a folder you pick; allow it. Next time the folder window opens where you saved last.

The Excel report

  • Read Me: where the data came from, how clashes were rated, and caveats.
  • Summary: Forma's totals next to the report's, counts by rating, and the types clashing most.
  • Clash Groups: one row per group, with its worst rating and where to find it in Navisworks (rating folder / group name, exactly as Model Coordination names it).
  • Clash Detail: one row per clash: both elements, their IDs, the overlap, and why it got its rating.

All totals are live formulas, so filtering and sorting are safe.

Into Navisworks Pro

  1. Open the coordination model (the NWF/NWD with the same Revit models).
  2. Viewpoints: open the Saved Viewpoints window, right-click in it, choose Import Viewpoints and pick the _Viewpoints_Shared.xml (or Internal) file.
  3. Search sets: open the Sets window, right-click, choose Import Search Sets and pick _SearchSets.xml.
  4. Click a viewpoint to jump to that clash group. Click its search set (same G### name) to select the clashing elements.

Search sets find each element by its Revit Element ID, or by the "[ID]" at the end of its name, so they work on both locally exported NWCs and models brought in from Forma.

Rating rules

Open Rating rules in the panel to tune them, then Save rules. Reset to defaults puts them back.

  • Overlap under Touch below (default 1/8") is Inconsequential.
  • A clearance or access zone on either side is Review.
  • Hanger hardware (rod, nut, washer, bolt, gasket, weld) up to Hard above (default 1") is Inconsequential, and deeper is Review.
  • A support against another trade, up to the Hard threshold, is Review.
  • Everything else is Consequential. A group takes the worst rating of its clashes.

The keyword boxes are matched against each element's family and type name, so add your own family names to them if your standards use different words.

Activate Pro

  1. Buy Pro on Gumroad ($9.99 one-time). Got a team code? Enter it at checkout.
  2. Copy the license key: it's on the purchase page Gumroad opens after checkout, and in your receipt email (four blocks of eight letters and numbers).
  3. Right-click the extension's icon in Chrome's toolbar and choose Options (or click License at the bottom of the export panel).
  4. Paste the key, click Activate. It says "Pro is active".
  5. Close and reopen the export panel. Viewpoints and Search sets are unlocked.

A key works in up to 5 browsers. To move to a new computer, click Remove key from this browser on the old one first.

Troubleshooting

No gold button on the viewer toolbar.
Reload the Forma tab (F5), and check the extension is switched on in chrome://extensions.
"Set Group clashes by to Object Name".
The export reads that grouping only. Change it in the clash panel and open the export again.
The counts don't match Forma, or groups weren't located.
Let the clash list and both models finish loading, then close and reopen the panel. Groups that can't be located still go in the Excel report, but get no viewpoint.
Navisworks says "The import failed".
Make sure you used Import Viewpoints for the viewpoints file and Import Search Sets for the sets file, and that the file came from version 0.3.1 or later.
A viewpoint lands in empty space.
Export again with the other coordinate option (Shared or Internal), to match how the models were exported from Revit.
A search set selects nothing.
Check the Navisworks model contains the same Revit models, at the same version, as the Forma clash check.
Pro boxes stay locked after activating.
Close and reopen the export panel. On the options page, Check license now shows whether Gumroad accepted the key.
