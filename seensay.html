Inspection Panel

See what's in your model. Diagnose what's hidden. Catch fab errors before the shop floor.

🔄
Sync Views
Match the pan, zoom, and rotation of the active view to one or more target views. Works across 2D plans (crop regions and zoom) and 3D views (camera position and orientation). Keeps coordination views aligned during review.
👁️
Element Visibility
Pick an element and two views — the tool walks every visibility condition (category, workset, filter, phase, design option, crop region, view range) and reports exactly which setting causes the difference. Stop manually toggling settings to find why something disappeared.
🔬
Snoop Selection
Deep-inspect any element's full property tree: parameters, properties, bounding box, connectors, fabrication data, and raw .NET members, with Similarities and Differences views for several elements at once. Essential for debugging API behavior, verifying parameter values, and understanding how Revit stores element data.
⚖️
Compare
Side-by-side comparison of fabrication parts, two families, two views or view templates, or schedules. Highlights every difference, filters to differences or matches, and exports to CSV or Excel. Verify consistency between similar elements or track changes between model versions.
🔎
Find Sheet
Select a view or viewport and instantly navigate to the sheet where it lives. Saves time hunting through the Project Browser on large models with hundreds of sheets.
🧹
Super Filter
Filter More on steroids. Load your selection, the active view or the whole model, then uncheck what you don't want in a Category › Family › Type tree or a Parameter › Value tree. Narrow again as often as you like, box-select to add more, and push the result into the Revit selection.
📐
Check Duct Orientation
Reads the connectors of rectangular fabrication duct to check that the labeled width really is the horizontal side. Flags pieces turned 90°, selects them in Revit, and fixes them with one click by rotating them back. Works on horizontal, sloped and vertical runs, with CSV export.
🌀
Coil Duct
Calculates overall cut length (body + connector allowances) for each rectangular fab straight and checks coil-machine eligibility. Tags and color-codes results: green = eligible, red = bad connector/shape, purple = exceeds coil width. Configurable connector profiles with import/export.

Designation Panel

Number it. Tag it. Convert it. Spin it. Sync the hangers.

🔢
Renumber
Writes sequential numbers with prefix, suffix and zero padding into up to three parameters. Order by size, clockwise or counterclockwise, along a picked curve, by parameter value, or in the order you click; group by category, family or type. Optionally gives identical parts the same number. Saves setups as profiles. Undo-safe.
🏷️
Place Tags
Batch-place tags on selected elements using saved tag profiles. Supports offset positioning, leader control, and multi-category tagging in a single pass. Profile system remembers your preferred tag family and settings per category.
🪟
View Converter
Converts Legend views to Drafting Detail views and back. Rebuilds detail curves, text notes, filled regions, annotation symbols, and dimensions directly in the new view. Options to delete the source, auto-open the result, and zoom to fit.
🔠
Toggle Case
Cycle TextNote elements between UPPERCASE, Title Case, and lowercase — like Shift+F3 in Word. Auto-Cycle mode detects the dominant case across your selection and advances to the next. Save profiles for your preferred mode.
🔄
Rotate Multiple
Rotates each selected element around its own center point — unlike Revit's native rotate, which uses a single shared axis. Enter an angle and every selected element spins in place. Built for adjusting diffusers, equipment, or fittings in bulk.
🔁
Convert
Replaces fabrication ductwork with native Revit ducts and fittings, in four passes: straights, elbows, transitions and taps. Sizes come from the fabrication connectors, and workset, phases, Comments, Mark and System Name carry over. Keep or delete the originals; one undo step per run.
🪝
Set Hangers
Pre-select duct or pipe (or pick after launching). Finds Generic Model RFA hangers near each run (1 ft by default, adjustable) and writes slope-interpolated BOH elevation, clamp size, trapeze width and insulation, then centers each hanger on the run. Upper Attachment makes hanger tops follow a sloped model line, and Quick Sync sets one hanger to one run.
