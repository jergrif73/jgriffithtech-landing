How it works

  1. Open Legend to Tool Chest. It opens in its own window.
  2. Zoom in on the legend, press Windows + Shift + S and snip the symbols you want, names included. Names can sit beside the symbols (P&ID style) or under them (duct fitting and equipment grids). Press Ctrl + V. Paste as many snips as you like.
  3. Answer the questions: a name for the tool set, how tall a typical symbol should be (1/8" to 1/2"), names as on the sheet or Title Case, colors, and line weight.
  4. Check the cards. Fix a name by typing over it, untick what you don't want, click a picture to recolor it.
  5. Press Add to Revu. The tool set appears at the bottom of your Tool Chest, and a copy is saved in Documents.

Install

  1. Buy on Gumroad and download JGT-Legend-to-Tool-Chest-Setup-0.6.0.exe from your receipt.
  2. Run it. No admin rights needed; it installs for your user account. If Windows shows "Windows protected your PC", choose More info, then Run anyway.
  3. Open Legend to Tool Chest from the Start menu. The user guide is in the Start menu too.

To update, run a newer installer; it closes a running copy for you. To remove it: Windows Settings, Apps, JGT Legend to Tool Chest, Uninstall. Your saved tool sets stay in Documents.

Help

The user guide covers snipping, every question, Fix boxes, colors, line weight, getting tool sets into Revu and taking them out again, and troubleshooting.

  • Symbols look rough: zoom in on the sheet 2 to 3 times before you snip, then try the line weight slider.
  • Two symbols became one tool: they touch on the drawing. Use Fix boxes to box each one.
  • Delete a tool set from Revu: Tool Chest, Manage Tool Sets, select it, Remove.
